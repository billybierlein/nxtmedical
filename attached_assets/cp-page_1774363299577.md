## **Replit Agent Instruction — Build Chiropractor Landing Page**

### **Objective**

Create a new landing page on the NXT website for chiropractors interested in NXT Remote Care services.

This page should be designed to convert cold and warm traffic from:

* outbound emails  
* LinkedIn / social traffic  
* direct website visits  
* intro video traffic

Primary page goal:

* get chiropractors to **book a demo**

Secondary page goal:

* get chiropractors to **watch the short intro video**

The page should clearly communicate that:

* NXT helps chiropractors create a new revenue stream from eligible Medicare patients  
* NXT handles the heavy lifting end to end  
* the chiropractor does **not** need to manage the operational burden  
* the chiropractor’s main role is to provide patient lists and review progress reports

### **Implementation requirements**

Build this page using the site’s **existing component structure and styling conventions** wherever possible.

Prefer reusing existing shared sections/components already used elsewhere on the site, such as:

* Hero  
* benefits grid / icon cards  
* FAQ section  
* CTA band  
* proof/stat/testimonial blocks if available

Do **not** over-engineer this page. Keep it lean, polished, and conversion-focused.

### **Recommended route**

Use one of these if no route has already been reserved:

* /for-chiropractors  
* /chiropractors  
* /remote-care/chiropractors

If the current site already has a naming convention for service vertical pages, follow that pattern.

### **8\. FAQ section**

Purpose:

* handle objections before the demo

Use your existing FAQ section component if available.

Recommended FAQs:

**1\. Do chiropractors need to manage the remote care program themselves?**  
No. NXT is designed to handle the operational side of the program so the clinic does not need to build a separate in-house process.

**2\. Is this a lot of extra work for the practice?**  
The goal is to keep the clinic’s role lightweight. Your team identifies appropriate patients and reviews progress updates, while NXT supports the rest of the workflow.

**3\. What type of patients are the best fit?**  
The best fit is generally clinics with eligible Medicare patient populations who may benefit from ongoing remote support and monitoring.

**4\. Do we need to hire staff to offer this?**  
No additional hiring should be required to explore the program. NXT is built to reduce the operational lift on the clinic.

**5\. What happens during the demo?**  
We walk through how the program works, what your clinic would be responsible for, what NXT handles, and whether the model appears to fit your patient population and goals.

**6\. Is this available nationwide?**  
The page can state broad availability only if that claim is already approved internally. If not, use softer wording such as “available in many markets” until confirmed.

Implementation note:

* If approved claims differ, update FAQ language accordingly  
* Keep answers short and skimmable
