## **Replit Agent Instruction — Build “Who We Serve” Page**

### **Objective**

Create a new **Who We Serve** page for the NXT website.

This page should serve as a simple directory-style hub for provider-specific landing pages. For now, it should include only **Chiropractors** as the live provider vertical.

This page is **not** meant to be the main sales/conversion page. Its job is to:

* give the site cleaner information architecture  
* create a scalable foundation for future provider verticals  
* support SEO/internal linking  
* route users to the correct provider page

For now, the main destination from this page should be the chiropractor landing page.

### **Primary page goal**

* guide visitors to the appropriate provider page

### **Current live provider category**

* Chiropractors

### **Future provider categories**

This structure should be easy to expand later for additional provider types, but do **not** create placeholder pages or empty cards for categories that are not ready yet.

---

## **Implementation requirements**

### **Route**

Create a route for:

```
/who-we-serve
```

### **Navigation**

Add **Who We Serve** as a top-level nav item if it is not already present.

Recommended behavior:

* top nav item: **Who We Serve**  
* dropdown or submenu may include **Chiropractors**  
* clicking **Who We Serve** should go to `/who-we-serve`  
* clicking **Chiropractors** should go to `/for-chiropractors`

If the current nav system does not support both cleanly, prioritize:

1. top-level link to `/who-we-serve`  
2. card-based link from that page to `/for-chiropractors`

### **Styling**

Use the site’s existing design system and shared layout components where possible.

The page should feel:

* clean  
* professional  
* healthcare-appropriate  
* simple and expandable

Do not over-design this page.

```ts

    title: "Chiropractors",
    description: "See how chiropractic clinics can explore remote care programs...",
    href: "/for-chiropractors",
  },
];
```

Use whatever structure best matches the current codebase.
